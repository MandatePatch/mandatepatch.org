# mandatepatch.org
Static public site for MandatePatch. Content: `index.html`. Deployed with GitHub Pages from `main`.
The specification is at https://www.tdcommons.org/dpubs_series/11517 and the reference implementation at https://github.com/MandatePatch/mandatepatch.
